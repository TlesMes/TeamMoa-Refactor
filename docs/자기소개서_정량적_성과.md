## 🐛 6. WebSocket 실시간 협업 버그 수정

### ALB 환경 동기화 문제 해결 (2025.12.16, 커밋 1c98734)
**문제**: ALB 멀티 서버 환경에서 접속자 정보 메모리 분산 → 동기화 실패

**해결**:
- **기존**: 클래스 변수 (메모리) 기반 접속자 관리
- **개선**: Redis 중앙 집중식 접속자 관리
  - `HSET`: 접속자 추가
  - `HDEL`: 접속자 제거
  - `TTL 24시간`: 자동 정리

**영향**:
- ALB 2대 서버 환경에서 실시간 협업 정상 작동
- 접속자 목록 동기화 **100% 보장**

### 실시간 협업 5개 이슈 수정 (2025.12.16, 커밋 2330e41)
1. ✅ 새 접속자에게 기존 접속자 목록 전송
2. ✅ 노드 생성 실시간 반영
3. ✅ 노드 삭제 실시간 반영
4. ✅ 마우스 커서 좌표 변환 정확도 개선
